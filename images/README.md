# Photos

Drop your real before/after photos in this folder, then edit the `GALLERY` list in `js/config.js`.

Tips for photos that look great in the slider:

- Take the **before** and **after** shot from the **same position and angle**, same zoom. The slider only works if the two line up.
- Landscape orientation, ideally 3:2 (e.g. 1200 x 800 px). Anything works, but keep both photos in a pair the same size.
- Shoot in daylight or shade, not direct sun, so the haze and the clarity both show clearly.
- Export as JPG or WebP under 400 KB each so the page stays fast. Free tools: squoosh.app.
- Name them anything you like, e.g. `before-audi-a3.jpg` / `after-audi-a3.jpg`, and reference the names in `js/config.js`.

The `placeholder-*.svg` files can be deleted once you have real photos.
